# A&G Store — موقع متجر عربي متجاوب

## ما الذي يتضمنه؟
- واجهة متجر عربية RTL بألوان الوردي والأبيض والأزرق.
- عرض المنتجات والصور والأسعار والخصومات والوصف والأقسام.
- بحث وتصنيف حسب القسم.
- زر طلب يجهز رسالة واتساب باسم المنتج وسعره.
- لوحة مدير بتسجيل دخول Supabase Auth.
- إضافة المنتجات وتعديلها وإخفاؤها وحذفها.
- رفع صور المنتجات إلى Supabase Storage.
- تعديل رقم الهاتف والواتساب والعنوان ووصف المتجر وروابط السوشيال.
- قاعدة بيانات مع سياسات RLS تمنع الزوار من تعديل البيانات.

## الملفات
- `index.html`: الموقع ولوحة الإدارة.
- `config.js`: إعداد الاتصال بمشروع Supabase.
- `supabase_setup.sql`: الجداول والصلاحيات ومخزن الصور.
- `README.md`: خطوات التشغيل.

## الإعداد لأول مرة
1. أنشئ مشروعًا مجانيًا في https://supabase.com/ وسجّل الدخول.
2. من SQL Editor شغّل كامل محتوى `supabase_setup.sql`.
3. من Project Settings → API انسخ Project URL و`anon`/publishable key إلى `config.js`.
   - لا تضع `service_role` key في الموقع نهائيًا.
4. من Authentication → Users أنشئ مستخدم المدير ببريد وكلمة مرور قوية.
5. انسخ UUID الخاص بالمستخدم، ثم نفّذ في SQL Editor مع استبدال القيمة:
   ```sql
   insert into public.admin_users (user_id)
   values ('UUID-OF-ADMIN-USER');
   ```
   لا تفتح التسجيل العام للمديرين؛ أنشئ حساب المدير بنفسك من لوحة Supabase.
6. افتح `index.html` محليًا للتجربة، أو ارفع الملفات الثلاثة إلى استضافة صفحات ثابتة مثل GitHub Pages أو Netlify.
   - لو المتصفح منع الاتصال أو التحميل عند فتح الملف مباشرة، شغّل الموقع من استضافة/خادم محلي.
7. افتح الموقع واضغط علامة الترس أسفل اليسار وسجّل دخول المدير.
8. من «بيانات التواصل» أضف رقم الهاتف والواتساب. استخدم رقم واتساب بصيغة دولية بدون `+` أو مسافات، مثل `2010XXXXXXXX`.
9. أضف المنتجات من لوحة المدير.

## ملاحظات مهمة
- قبل ربط Supabase يعرض الموقع بيانات تجريبية فقط؛ أي تغييرات لا تُحفظ في قاعدة بيانات.
- هذا المشروع يوفّر كتالوجًا وطلبًا عبر واتساب، وليس دفعًا إلكترونيًا أو نظام مخزون/شحن/حسابات عملاء.
- الصور التي تُرفع لا تُحذف تلقائيًا من Storage عند حذف المنتج؛ راجع Storage لتنظيف الصور غير المستخدمة.
- لا تشارك كلمة مرور المدير أو مفاتيح سرية. المفتاح الموجود في `config.js` يجب أن يكون anon/publishable فقط، والحماية تعتمد على سياسات قاعدة البيانات.
- أنشئ نسخة احتياطية من قاعدة البيانات عند التوسع.
